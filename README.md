# 词境 · Context Reader

词境浏览器阅读插件的宣传网页：在语境中读懂，在原句中记住。

页面展示语境释义、拼写纠错提示、原句复习，以及 Chrome / Edge 插件的下载和安装说明。

## 网页说明

- 本站为静态网页，使用 HTML、CSS 和 JavaScript。
- 页面里的交互示例采用预设释义，不调用 AI，也不收集 API Key。
- 实际插件由用户在插件设置里配置自己的 DeepSeek API Key。
- 文件使用相对路径，可通过 GitHub Pages 发布。

## 发布

GitHub 仓库的 Settings → Pages 中，选择从 `main` 分支根目录发布。根目录的 `.nojekyll` 表示直接提供静态文件。
